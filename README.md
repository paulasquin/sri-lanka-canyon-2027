# Sri Lanka Canyon 2027

Site statique (GitHub Pages) de l'expédition : `index.html`, `css/`, `js/data.js` (contenu), `js/app.js` (cartes MapLibre, animations GSAP).

En local : `python3 -m http.server` puis http://localhost:8000.

Le site n'est pas destiné aux moteurs de recherche : balises `noindex` dans `index.html`. Ne pas ajouter de `Disallow` dans un robots.txt, sinon les robots ne lisent plus la balise `noindex`.
